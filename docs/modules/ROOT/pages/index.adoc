= Insurance AI Use Case
:description: AI-powered insurance workflows on GoldenRay AI Platform
:page-layout: home

== Overview

This project demonstrates three production-ready AI use cases for the insurance industry, powered by the *GoldenRay AI Platform*:

[cols="1,3"]
|===
|Use Case |Description

|*Claims Processing*
|Automated extraction, classification, and routing of insurance claims using LLM-powered document analysis.

|*Underwriting*
|AI-assisted risk scoring and premium calculation combining rule-based models with LLM narrative generation.

|*Customer Agent*
|RAG-powered conversational agent that answers policy questions using retrieved insurance documents.
|===

== Why GoldenRay?

* **Model-as-a-Service (MaaS)**: Unified API for any model — from TinyLlama demos to GPT-4o production
* **Guardrails**: Automatic PII detection and redaction for insurance-sensitive data (SSN, medical codes, policy numbers)
* **MLflow Integration**: Track experiments, model versions, and inference quality
* **Flyte Pipelines**: Orchestrate claims processing and model training workflows
* **Multi-Tenant**: Isolate models and data per team or department

== Quick Start

[source,bash]
----
# Clone the repository
git clone https://github.com/riteshshah-wq/insurance-use-case.git
cd insurance-use-case

# Run locally
pip install -r requirements.txt
uvicorn app.api:app --reload

# Or deploy to Kubernetes
kubectl apply -f k8s/
----

Then visit http://localhost:8000/docs for the interactive API documentation.
